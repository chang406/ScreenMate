## 1. 시스템 트레이 (P0)

- [ ] 작업표시줄에 ScreenMate 오버레이 버튼이 **보이지 않는다**
- [ ] 시스템 트레이(시계 옆, `^` 숨은 아이콘 포함)에 ScreenMate 아이콘이 있다. 마우스를 올리면 "ScreenMate" 툴팁
- [ ] 트레이 아이콘 **좌클릭** → 캐릭터 숨김 / 다시 좌클릭 → 다시 나타남
- [ ] 트레이 **우클릭** 메뉴: 캐릭터 숨기기/보이기, 캐릭터 매니저 열기, 항상 위에 고정(✓), 위치 잠금, 종료
- [ ] 트레이 메뉴 "캐릭터 숨기기" 후 메뉴 글자가 "캐릭터 보이기"로 바뀐다
- [ ] 트레이 "항상 위에 고정" 체크 해제 → 캐릭터 우클릭 메뉴에도 `항상 위에 고정: OFF`로 반영 (반대 방향도)
- [ ] 캐릭터 우클릭 → "트레이로 숨기기" → 트레이 좌클릭으로 복귀
- [ ] 트레이 "종료"로 앱이 정상 종료된다

## 2. 시작 위치 & 위치 잠금 (P0)

> 테스트 후 사용자 결정으로 "마지막 위치 기억"은 **"항상 화면 가운데에서 시작"**으로 바뀌었습니다(PR #2).

- [ ] 어디에 두고 종료하든 재실행하면 **주 모니터 정중앙**에서 시작한다
- [ ] 우클릭 → "위치 잠금" ON → 드래그해도 창이 움직이지 않고 "🔒 위치가 잠겨 있어요" 말풍선 / 클릭 반응은 여전히 동작
- [ ] 트레이 메뉴의 "위치 잠금" 체크 상태가 오버레이와 일치

## 3. 크기 슬라이더 & 효과음 (P1)

- [ ] 우클릭 메뉴 슬라이더로 60%~200% 사이 1% 단위 크기 조절, 프리셋 버튼/휠과 값이 동기화
- [ ] 효과음 기본값이 **OFF**
- [ ] 효과음 ON 시 미리 듣기 차임이 들린다. 볼륨 슬라이더가 동작한다
- [ ] 앱 재시작 후(효과음 ON 상태 저장됨) AI 작업 완료 시 차임이 **첫 클릭 전에도** 들린다
  - ⚠️ 들리지 않으면: WebView2 자동재생 정책 때문일 수 있음. 캐릭터를 한 번 클릭한 뒤에는 들리는지 메모해 주세요
- [ ] 에러 시 낮은 2음, 캐릭터 클릭 시 짧은 "팝"

## 4. AI 에이전트 감시 정확도 (핵심 가치)

**Claude Code**로 파일을 읽고/수정하고/명령을 실행하는 작업을 하나 시켜 보세요.
- [ ] 도구를 쓸 때마다 "생각 중" 대사로 **깜빡이지 않고** `busy` 대사(코딩 중/명령어 실행 중/파일 읽는 중)가 유지된다
- [ ] 작업이 끝나면 `talking`(완료) 반응
- [ ] Esc로 작업을 중단하면 `idle`로 돌아간다
- [ ] **새 대화**를 시작한 직후 첫 질문에 바로 `thinking` 반응 (예전에는 첫 반응을 놓칠 수 있었음)
- [ ] 캐릭터 매니저 → `📡 AI 에이전트 연결` 탭에서 세션 개수가 표시된다

(설치되어 있다면) **OpenAI Codex CLI** 로 같은 작업:
- [ ] `~/.codex/sessions/…/rollout-*.jsonl` 세션에 반응한다 (예전에는 무반응)
- [ ] `apply_patch` 중 "코딩 중" 계열 대사

## 5-1. 작은 화면 · 배율 대응 (후속 PR: 창 크기 자동 맞춤)

> 노트북이 없어도 재현할 수 있습니다: Windows 설정 → 디스플레이 → **배율 150%** 또는 **해상도 1366×768**로 바꾼 뒤 앱을 실행하세요.

- [ ] 작은 화면/높은 배율에서 실행해도 캐릭터 전체가 화면 안에 보이고 드래그할 수 있다
- [ ] 우클릭 메뉴가 화면 안에 표시된다
- [ ] 200%로 키워도 캐릭터가 창 위쪽으로 잘리지 않는다
- [ ] 캐릭터를 어디로 끌어다 놓아도 **그 자리에 그대로 있다** (얼굴만 빼꼼 내놓기, 화면 밖으로 휙 숨기기 가능)
- [ ] **위·아래·좌·우 모두** 화면 밖으로 숨길 수 있다 (예: 발을 잡고 화면 위 끝까지 끌면 발만 남고 위로 숨겨짐). 붙잡은 지점은 커서와 함께 화면 안에 남는다
- [ ] 드래그가 끊기거나 버벅이지 않고 부드럽다, 놓은 뒤 캐릭터가 마우스를 따라오지 않는다
- [ ] 우클릭 → "🏠 화면 가운데로 불러오기" → 캐릭터가 있는 모니터 정중앙으로 온다
- [ ] 트레이 → "캐릭터 화면 가운데로 불러오기" → 주 모니터 정중앙으로 온다 (우클릭할 수 없을 만큼 숨긴 경우)
- [ ] (모니터 2대, 배율이 다르면) 다른 모니터로 옮긴 뒤 크기가 그 모니터에 맞게 다시 조정된다
- [ ] 배율을 원래대로 되돌리고 재실행하면 원래 크기(640×920)로 돌아온다
